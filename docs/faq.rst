General
-------

Does sealwatch do steganography?
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

No, for steganographic embedding,
see our sister project `conseal <https://conseal.readthedocs.io/>`__.


Contributing
------------

Are you open for contributions?
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Absolutely. You are highly encouraged to contribute implementations of steganalysis methods.
To ensure quality, we ask you to

- contribute only concepts supported by peer-reviewed research,
- document your code sufficiently, using docstrings and comments, and
- cover your contribution with unit tests,
  comparing the outputs to an existing reference implementation.

Where do I report a bug?
^^^^^^^^^^^^^^^^^^^^^^^^

Open an issue on `GitHub <https://github.com/uibk-uncover/sealwatch/issues>`__.
